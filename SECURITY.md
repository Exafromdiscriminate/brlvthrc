## 🛠 Troubleshooting

### Processing causing artifacts

```powershell
# Reduce processing amount
# De-Noise > Amount = 50% (not 100%)

# Multiple passes
# Process 50% twice instead of 100% once—less aggressive

# Check preview
# Always preview before applying to full file
```

### Dialogue Isolate not working

```powershell
# Check audio complexity
# Works best on dialogue with clear voice—fails on heavy music background

# Adjust sensitivity
# Dialogue Isolate > Sensitivity = 5-7 (default 6)

# Use De-Reverb first
# Heavy reverb confuses AI—remove reverb before dialogue isolation
```
